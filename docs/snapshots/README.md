# AWX Podman Pod Snapshots

These snapshots show the example AWX browser environment started from
`pod.example.yaml`.

- `awx-pod-login.png` captures the unauthenticated login screen.
- `awx-pod-dashboard.png` captures the first authenticated overview screen for
  the example admin account.

The screenshots are reference artifacts for the smoke-test example. They do not
contain real credentials or production data.
