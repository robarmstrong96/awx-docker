# Third-Party Notices

This file is a placeholder for the public-release notice bundle.

Private Milestone 1 images are built from upstream AWX plus operating system, Python, and JavaScript dependencies. Before any public image publication, CI must generate and retain a complete SBOM and third-party notice/license bundle for the built image.

The Milestone 1 `build/evidence/` files are build provenance hints only. They are not a substitute for the public-release SBOM and notices bundle.

Known primary upstream:

- AWX: https://github.com/ansible/awx, Apache-2.0
